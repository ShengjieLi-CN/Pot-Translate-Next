# 夸克网盘同步（OpenList）

在“备份设置”选择“夸克网盘”，填写自己的 OpenList 服务地址、服务令牌和完整的夸克备份目录。夸克账号由 OpenList 管理，Pot 不再使用夸克直连授权、应用 ID 或签名密钥。OneDrive 和阿里云盘保持移除状态；WebDAV、本地备份及项目仓库更新检查继续保留。

## 配置

1. 在自己的 OpenList 服务中挂载并授权夸克网盘，保持存储在线。
2. 在该存储内建立专用目录，例如 `/夸克/Pot Translate Next`。
3. 在 Pot 填写服务地址（例如 `https://drive.example.com`）、OpenList 服务令牌和该目录的完整路径。
4. 点击“保存设置”或“测试连接”，成功后可“立即同步”或“恢复备份”。

令牌对应的用户需要该目录的列表、刷新、读取、上传和删除权限。此版本不支持设有额外访问密码的目录。服务地址使用 HTTPS；本机 `localhost`、`127.0.0.1`、`[::1]` 可以使用 HTTP。支持带子路径的服务地址，例如 `https://example.com/openlist`。

已保存的令牌不会传回界面，输入框留空表示保留。更换服务地址时须重新输入令牌，防止把原服务的凭据发送到其他服务。令牌单独保存在当前应用配置目录的 `quark-openlist.json`，不放入备份 ZIP。若检测到早期 OpenList 版本保存的完整配置，会尝试自动沿用。

## 同步、恢复与删除

- “立即同步”生成包含当前配置、翻译历史及插件的 ZIP，并同步上传到配置目录。只有 OpenList 确认同步上传成功，Pot 才显示成功；后台排队任务不会被当成已完成。
- “恢复备份”列出目录内全部 ZIP 文件，也支持旧备份文件名。恢复前会确认覆盖并校验 ZIP，成功后重启应用。
- 列表中的“删除”通过 OpenList 删除单个选定备份，需要确认。
- “打开 OpenList”可在浏览器中管理服务和夸克存储。

如果恢复下载失败，请在 OpenList 夸克存储中启用 Web 代理，并检查服务外部地址配置。Pot 使用 OpenList 返回的下载地址，服务令牌只发送到同源服务路径，不转发到外部下载地址或跨域重定向。

本功能采用手动 ZIP 快照，不自动覆盖本地配置。翻译服务配置中可能含接口密钥，请使用自己的私有存储。此前夸克直连的本机授权文件不再使用；已有云端文件不作自动删除或迁移。

接口参考：[OpenList API](https://openlist.apifox.cn/)。真实夸克读写需要配置可用的 OpenList 服务及令牌后验证。
