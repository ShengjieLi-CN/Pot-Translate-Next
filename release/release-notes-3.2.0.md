# Pot Translate Next 3.2.0

Windows x64 简体中文正式版，仅提供中文版 MSI 安装包。后续开发、打包及发布统一维护简体中文版；翻译语言仍支持原有多语种。

## 新增与改进

- **窗口置顶**：主窗口左上角新增图钉按钮，点击置顶并高亮，再次点击取消。
- **划词翻译**：拖选或双击文字后显示“译”按钮，点击打开仅译文浮窗；支持复制、关闭、快捷键和失败重试。可选择翻译服务及目标语言。
- **划词兼容性**：使用鼠标事件监听，减少快速划词和双击漏检。按钮不抢走原文焦点；点击后显示取词进度，UIA 不可用或超时时使用兼容取词，避免旧请求覆盖新选区。
- **段落与格式**：译文保留原文段落，合并 PDF 排版断行及服务额外产生的换行，不逐句另起一行；允许随窗口宽度自然折行。划词浮窗保留来源应用可提供的段落字体、字号、粗体和斜体。
- **STT 模型测试**：使用当前填写的配置和内置合成语音测试，显示转写结果、耗时、说话人标签及错误提示，无需录音或先保存配置。
- **同声传译**：支持 Windows 系统声音与麦克风、自定义兼容 STT 接口、说话人关联、逐段翻译、暂停继续、回放、音频导入及字幕导出。
- **截图翻译**：框选后原位显示译文，支持 OCR、专业术语提示、断词恢复、段落与双栏布局、原图对照和复制。

## 下载与安装

- `Pot.Translate.Next_3.2.0_x64_zh-CN.msi`：简体中文安装向导。
- 附带 `SHA256SUMS-3.2.0.txt` 供校验。

适用于 Windows 10/11 x64。沿用 Pot Translate Next 的应用标识，保留已安装 MSI 的升级关联。安装器包含 WebView2 安装引导程序；缺少 WebView2 时可能需要联网安装运行时。

本次 MSI 未配置代码签名证书。翻译、OCR 和 STT 服务需自行配置；不附带个人 API Key、STT 模型权重或预置云端服务。说话人分离效果取决于 STT 服务返回的信息，复杂文档的排版与识别效果取决于来源应用、OCR 和翻译模型。

真实付费服务的准确率和各第三方文档应用的划词效果需按实际配置检查。
