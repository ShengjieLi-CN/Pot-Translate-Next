# Pot Translate Next 3.2.1

Windows x64 简体中文版。此版本汇总 3.2.0 后的功能更新与修复，仅提供中文版 MSI。

## 新增功能

- **四种背景材质**：无（默认不透明）、Mica、Acrylic、Apple Liquid Glass 风格；不支持材质时回退至不透明背景。Liquid Glass 为应用内视觉模拟。
- **自动输入翻译**：输入或粘贴后停顿约 0.6 秒自动翻译；兼容中文输入法，过滤过期响应；Enter 可立即翻译。
- **LibreTranslate 离线翻译**：支持中译英和英译中。首次从“服务设置”下载运行环境及模型，完成后可在本机离线翻译，无需 API Key 或单独安装 Python / Docker。
- **千问 STT 默认配置**：同声传译默认采用阿里千问接口模板，保留自定义兼容服务及模型可用性测试。

## 修复与体验改进

- **复杂截图识别与定位**：保留 Paddle OCR 原始文字坐标，提高检测分辨率，避免大截图缩小导致的小字漏识别；自动模式下为英文画面选择已安装的英文模型。
- **Windows OCR 增强**：放大小字号文字，分块处理大图；缺少英文语言包时为英文画面提供内置 Tesseract 英文模型后备识别。
- **截图排版**：按局部区域区分多栏、卡片、标题及正文，识别放大后的坐标映射回原图；按局部底色覆盖译文，保留图形和背景。数字、取件码等不送入翻译模型改写。
- **中英混合界面**：按文字块修正翻译方向，避免中文菜单导致旁边的英文正文被跳过。
- **划词按钮恢复**：统一浮窗 WebView2 参数，修复选中文字后不出现“译”按钮的问题；增加拖选检测后备路径，关闭浮窗后可再次正常使用。
- **界面精简**：截图翻译从快捷键或托盘启动；移除截图、划词翻译的独立导航页面，划词设置并入“翻译设置”。移除输入翻译顶部的 LibreTranslate 管理面板，离线引擎在“服务设置”管理。
- **窗口修复**：解决透明材质下标题栏控制按钮重复显示的问题。

## 下载与安装

- `Pot.Translate.Next_3.2.1_x64_zh-CN.msi`：Windows x64 简体中文安装包。
- `SHA256SUMS-3.2.1.txt`：SHA-256 校验文件。

沿用现有应用标识和 MSI 升级关联。请退出旧版后安装；保留用户配置和离线模型。未配置代码签名证书；缺少 WebView2 时，其安装引导可能需要联网。窗口材质效果取决于 Windows 支持情况。

OCR、翻译和 STT 的准确率取决于所选服务；艺术字、旋转文字和复杂表格仍可能需要重新框选。云端服务需自行填写凭据；发布文件不含个人设置、密钥或用户录音。
