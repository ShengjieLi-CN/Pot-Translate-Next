# Pot Translate Next 3.2.2 简体中文版

- 划词“译”按钮改为圆形，修复透明窗口边角白边。
- 划词译文浮窗新增置顶开关；置顶后切换应用仍可查看译文，关闭浮窗后重置状态。

- 仓库首页使用合成内容演示图，不包含个人信息；详细更新说明集中在 Release。

## 下载与验证

Windows x64 简体中文版：`Pot.Translate.Next_3.2.2_x64_zh-CN.msi`。校验值见附件 `SHA256SUMS-3.2.2.txt`。安装包沿用既有升级标识。

已通过 61 项前端单元测试、18 项原生测试及划词、自动输入、复杂截图和备份界面回归。3 项需要真实设备或模型的原生测试未运行。已核验 MSI 版本、中文语言标识及解包程序哈希。夸克同步采用模拟服务验证，实际使用需自行配置 OpenList，未使用个人网盘账户进行验证。

离线引擎首次使用仍需下载模型；在线翻译和语音服务需自行配置服务凭据。安装包未进行代码签名。
