# Pot Translate Next 3.3.0 简体中文版

## 更新内容

- 划词翻译窗口默认宽 300、高 400，随系统显示缩放适配。
- 译文较多时优先增加高度，再适当加宽；达到自动调整上限或屏幕可用范围后滚动显示，保留手动调整尺寸。
- 支持多个划词翻译窗口同时打开。新划词不会覆盖已有译文；各窗口独立置顶、切换翻译服务、复制和关闭，Esc 只关闭当前窗口。
- 先读取选中文字，再创建独立结果窗口，减少新窗口对原文焦点的干扰。浮窗仍只显示译文，并保留原文朗读功能。
- 改善截图翻译中编号列表、悬挂缩进和宽间距文字的组合，避免不同列表项被错误合并。

## 安装与校验

仅提供 Windows x64 简体中文版：`Pot.Translate.Next_3.3.0_x64_zh-CN.msi`。SHA-256 校验值见附件 `SHA256SUMS-3.3.0.txt`。

3.2.7 及以上版本可在应用内检查、下载并安装更新；也可下载 MSI 升级。沿用既有升级标识，保留原有配置。安装需要 Windows 管理员授权；安装包未进行代码签名。

## 验证

- 64 项前端单元测试、21 项原生测试通过；3 项依赖真实音频设备、Windows OCR 环境或离线模型的测试按原有设置跳过。
- 划词、自动输入翻译、应用内更新和复杂截图界面回归通过；界面回归使用模拟翻译服务。
- 从 MSI 解包的程序完成 Windows 实测：真实原生文本框取词、3 个窗口独立运行、300×400 默认尺寸、置顶后继续划词、手动尺寸保留、独立关闭及 Esc。长内容自动放大和滚动使用合成测试数据验证。
- 已核验 MSI 产品名称、3.3.0 版本、简体中文语言标识、x64 架构、升级标识，以及包内程序与构建产物的 SHA-256 一致性。
