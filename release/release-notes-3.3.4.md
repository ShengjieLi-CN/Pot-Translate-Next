# 3.3.4 本地升级说明

- 修复单行项目较多时，段落间距被误当作普通行距，导致多项正文合并的问题。
- 对原截图文字左侧的圆点进行像素检测；要求标记形状紧凑、重复对齐，并排除邻栏文字和边框。即使 Paddle 没有识别出圆点，也能按项目分段。
- 在分段前等待对应截图的像素准备完成，保留每项续行、原始位置和复制译文的段落边界；不增加云端 OCR 请求，也不引入本地 OCR 模型。

验证：87 项自动测试通过；新增界面回归覆盖七项与四项、深浅背景、150% DPI、逐段翻译、复制和重试缓存。使用用户提供的完整截图及应用实际裁剪图的真实 Paddle 结果、腾讯翻译接口，均验证为标题加七个独立项目，无重叠或溢出。既有双栏论文、复杂截图及常规截图界面回归通过。
