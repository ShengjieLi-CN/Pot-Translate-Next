# Pot Translate Next 3.3.5 简体中文版

本次正式发布包含 3.3.0 之后的 Paddle OCR 统一、截图提速和段落修复，以及项目结构与发布流程整理。

## 更新内容

- OCR 统一使用 Paddle 官方云端服务。在“文字识别”页面选择模型并填写 AI Studio API Key；默认 PP-OCRv5，另支持 PP-OCRv6 和 PP-OCRv5-latin。
- 移除“服务设置 → 文字识别”和 OCR 提供商选择，清理停用的系统 OCR、Tesseract、旧提供商及其专用依赖和模型资源。翻译插件、朗读和收藏仍可独立配置。
- 上传图片压缩、同图短期缓存和最多三个区域并行翻译，减少重复识别和串行等待；翻译重试复用识别结果。
- 改善宽幅截图空结果、双栏混排及段落缩进处理。恢复 OCR 遗漏的原图圆点，保留四项、七项等列表的独立段落及续行。
- 修复贴着截图边缘的已识别文字被整行删除，以及圆点后没有空格时仍合并项目的问题。
- 统一文字识别与图片翻译的换行整理逻辑，补充模块、开发和发布文档；安装包校验自动读取当前版本。

## 安装与配置

下载 `Pot.Translate.Next_3.3.5_x64_zh-CN.msi`；SHA-256 见附件 `SHA256SUMS-3.3.5.txt`，包内程序验证信息见 `verification-3.3.5.json`。

3.2.7 及以上版本可在应用内检查更新，也可手动安装 MSI。沿用原有升级标识并保留配置；安装需要 Windows 管理员授权。安装包未进行代码签名。

从 3.3.0 或更早版本升级后，需要在“文字识别”页面填写 Paddle 云端凭据。OCR 需要联网，不再提供系统或本地 OCR 方案；现有 LibreTranslate 离线翻译功能不受影响。云端耗时受网络及服务排队影响。

## 验证

- 87 项 Node 自动测试通过，包含审查中发现的贴边文字及无空格项目符号回归。
- Paddle 设置与识别入口、常规截图、复杂图文、四项/七项列表的浏览器回归通过，覆盖 150% DPI、深浅背景、复制、取消、重试和旧提供商隔离。
- 自动测试与界面回归使用模拟服务，不要求个人 API Key。

模块结构和维护流程见仓库 `docs/ARCHITECTURE.md`、`docs/DEVELOPMENT.md`、`docs/RELEASING.md`。
