# Pot Translate Next 3.3.6 简体中文版

修复有道 TTS 返回 HTTP 500、火山 TTS 长文本返回空音频时导致朗读中断的问题。

## 更新内容

- 划词窗口、原文和译文共用朗读流程。长文按 UTF-8 请求大小分段，每段音频独立解码并按原文顺序播放，保留全部文字。
- 首选服务报错时，按已配置顺序尝试其他已启用、支持当前语言的语音服务，并显示实际使用的服务。本次朗读跳过已失败的服务；后续段落失败时只重试尚未播放的部分。
- 停止朗读会停止当前播放，并阻止后续分段请求和过期响应播放。
- 将服务端返回的数字字节数组解码为可读错误；所有服务失败时保留服务名称和原因。

有道 `/dictvoice` 在实测中对部分普通句子返回 `returned null audio`；这是上游服务故障，客户端通过切换已启用的备用服务维持朗读。若只启用有道且该请求失败，仍会显示错误，需要启用可用的备用服务。

- 划词界面回归及三个朗读入口回归通过，包含禁用服务跳过、语言及插件配置传递。
