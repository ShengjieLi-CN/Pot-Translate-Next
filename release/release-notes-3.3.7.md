# Pot Translate Next 3.3.7 简体中文版

本次正式发布包含 3.3.5 之后的语音合成修复与默认服务调整。

## 更新内容

- 移除“服务设置 → 语音合成”中的“添加内置服务”入口及 Lingva 语音服务实现，保留外部语音插件入口。
- 默认使用火山 TTS。首次安装自动准备火山插件；升级时复用现有火山实例、启用并移到首位，保留音色、实例名称和其他插件设置。
- 迁移仅执行一次，之后仍可自行调整语音服务顺序。旧 Lingva 语音实例从可用服务列表清除。
- 修复火山长文本返回空音频：按请求大小分段，每段独立解码并顺序播放，保留全部文字；停止朗读后不再请求后续段落。
- 修复首选语音服务失败即中断的问题：按配置顺序尝试已启用的备用服务，并显示实际使用的服务；支持划词窗口、原文和译文朗读。
- 将有道 HTTP 500 的数字字节数组转换为可读错误，所有服务失败时显示服务名称和原因。

## 安装与说明

下载 `Pot.Translate.Next_3.3.7_x64_zh-CN.msi` 安装，或通过应用内检查更新升级。安装需要 Windows 管理员授权，保留现有配置；安装包未进行代码签名。

有道 `/dictvoice` 对部分文本仍可能返回服务端空音频错误。新版默认优先使用火山，并可在失败时尝试其他已启用的语音服务；云端服务可用性取决于上游。
