# Pot Translate Next 3.3.9 简体中文版

新增 RapidOCR 为默认 OCR 引擎，同时保留 Paddle OCR 云端选项。

- “文字识别”顶部提供默认引擎选择；RapidOCR 设置位于 Paddle OCR 上方，提供安装状态、下载 / 修复和 CPU 线程数。
- RapidOCR 使用独立的本地 CPU 环境和随包模型，无需 API Key 或自行安装 Python。首次安装需联网，之后识别无需联网。
- 截图翻译、文字识别及输入窗口的图片识别统一遵循默认引擎选择；保留旧有 Paddle 模型和密钥。
- 复用模型和识别结果，保留长行补识别、段落与坐标处理；本地错误不会自动转为云端上传。

## 验证

- 107 项 Node 测试通过；24 项常规 Windows 原生测试通过。
- 真实 Windows RapidOCR 进程验证通过，包括文字与坐标、无效图片后请求同步和禁用网络后的推理。
- 中英文合成截图约 1.0 秒；此前出现内容缺失的宽幅截图约 1.2 秒，关键人名和延期说明完整识别。耗时为本机样例，不代表所有设备和图片。
- RapidOCR / Paddle 设置、三个识别入口、复杂图文、列表、150% DPI、重试和缓存回归通过。
- Windows x64 中文 MSI 校验通过，本地升级退出码 0；安装程序版本和哈希与构建产物一致。启动后默认 OCR 为 RapidOCR，本地引擎就绪，原有 Paddle 配置保留。

仅提供 Windows x64 简体中文 MSI。安装包不包含模型，首次使用请在“文字识别”安装 RapidOCR 引擎。Paddle OCR 仍需用户提供 AI Studio 访问令牌；翻译文字由所选翻译服务处理。
