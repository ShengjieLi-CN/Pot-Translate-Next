# Pot Translate Next 3.4.0 简体中文版

划词翻译统一接入旧版翻译窗口，原文编辑、语言选择和多个翻译服务共用一套逻辑。

- 划词按钮和划词快捷键都会把取词结果送入旧版翻译窗口。
- 保留原文编辑、源语言与目标语言选择，以及常规、专业、备用翻译服务和多服务译文卡片。
- 连续划词在同一套旧版窗口流程中更新内容，不再使用独立的“仅译文”结果窗口。
- 移除“仅译文”窗口专属的服务、目标语言和透明度设置；通用翻译设置继续生效。
- 仅维护和发布 Windows x64 简体中文版。

## 安装与验证

- 从本页下载 `Pot.Translate.Next_3.4.0_x64_zh-CN.msi`，可直接升级现有安装；个人服务和配置保留在本地。
- 划词界面及真实 Windows 取词链路已验证。
- MSI 产品版本、简体中文语言、x64 架构、固定升级标识和内置程序哈希均通过校验。
- 本地升级退出码为 0；安装后的程序版本与内置程序哈希一致，配置文件保留。
- `SHA256SUMS-3.4.0.txt` 和 `verification-3.4.0.json` 随安装包提供。

仅提供 Windows x64 简体中文 MSI。翻译文字由用户所选服务处理，发布文件不包含个人配置或凭据。
