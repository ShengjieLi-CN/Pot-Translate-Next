# Pot Translate Next 3.4.1 简体中文版

精简划词翻译界面模式，并将文字识别统一为本地 RapidOCR 推理模型。

- 划词翻译窗口移除顶部的“英汉互译”和“常规翻译”切换选项，合并为常规翻译，保留原文编辑、语言选择与多服务译文卡片。
- 主窗口输入翻译保留原文与译文逐句对照高亮能力。
- 文字识别设置移除 Paddle OCR 云端引擎选择、模型与 API Key 配置，仅保留本地 RapidOCR 推理模型及 CPU 线程数设置。
- 后端启动校验自动将历史配置中的 `ocr_provider` 迁移并锁定为 `rapidocr`。
- 仅维护和发布 Windows x64 简体中文版。

## 安装与验证

- 从本页下载 `Pot.Translate.Next_3.4.1_x64_zh-CN.msi`，可直接升级现有安装；个人服务和配置保留在本地。
- 前端 92 项单元测试与生产构建通过。
- MSI 产品版本、简体中文语言、x64 架构、固定升级标识和内置程序哈希均通过校验。
- 本地升级退出码为 0；安装后的程序版本与内置程序哈希一致，配置文件保留。
- `SHA256SUMS-3.4.1.txt` 和 `verification-3.4.1.json` 随安装包提供。

仅提供 Windows x64 简体中文 MSI。翻译文字由用户所选服务处理，发布文件不包含个人配置或凭据。
